# Сайт дилера прального обладнання

## Як усе влаштовано

| Що | Де |
|---|---|
| Назва, контакти, цифри, відгуки, запитання | `data/site.json` |
| Категорії та товари (назви, ціни, характеристики, фото) | `data/products.json` |
| Фото товарів | `img/products/` (два розміри: `назва.webp` і `назва-sm.webp`) |
| Картинка першого екрана (машини в ряд) | `img/hero/`, складається скриптом `tools/make_showroom.py` |
| Оформлення | `css/styles.css` |
| Кошик, форми, меню | `js/app.js` |
| Скрипт, що збирає готові сторінки | `build.py` |
| Готовий сайт (створюється автоматично, руками не редагувати) | `dist/` |

## Як щось змінити

1. Відредагуйте `data/site.json` або `data/products.json` у будь-якому текстовому редакторі.
2. Зберіть сайт:

```bash
python3 build.py
```

3. Перегляньте результат:

```bash
python3 -m http.server 8080 --directory dist
```

і відкрийте http://localhost:8080

Встановлювати нічого не потрібно: Python 3 уже є на Mac.

## Демо-режим

У `data/site.json` є перемикач `demoMode`.

- `true` — сайт показує умовні дані з розділу `demo` (вигадані контакти, цифри, відгуки, ціни, частина товарів). Зверху червона стрічка «Демо-версія», пошуковикам заборонено індексувати.
- `false` — сайт показує лише те, що заповнено в розділі `real`. Порожні значення і цілі блоки просто зникають; вигадані товари (`"demo": true`) теж.

Подивитися, як сайт виглядає без демо-даних, не змінюючи налаштувань:

```bash
python3 build.py --real --out dist-real
```

## Друга колірна версія (синя)

Основна версія — з бірюзовим акцентом. Щоб зібрати таку саму, але з синім акцентом, в окрему папку:

```bash
python3 build.py --theme blue --out dist-blue
```

## Перед публікацією

1. Заповнити розділ `real` у `data/site.json` (скрипт збирання щоразу друкує список незаповненого).
2. Вписати підтверджені ціни (`price`) і характеристики (`specs`) у `data/products.json`; вигадані товари замінити справжніми.
3. Вказати `siteUrl` (адресу сайту) — тоді зʼявляться `sitemap.xml` і канонічні адреси сторінок.
4. Вказати `formEndpoint` — адресу, куди надсилати заявки. Без неї форми чесно повідомляють, що заявку не надіслано, і показують телефон.
5. Дати текст політики конфіденційності на перевірку юристу.
6. Поставити `demoMode: false` і зібрати сайт.

## Сайт в інтернеті (GitHub Pages)

- Код: https://github.com/Ievgeniyyyy/laundry-site
- Сайт: https://ievgeniyyyy.github.io/laundry-site/

GitHub показує вміст папки `docs/`. Щоб оновити сайт в інтернеті після змін:

```bash
python3 build.py --out docs --base /laundry-site
```

```bash
git add -A && git commit -m "Оновлення сайту" && git push
```

Синя версія для порівняння лежить за адресою https://ievgeniyyyy.github.io/laundry-site/blue/ . Перша команда вище її стирає, тож після неї зберіть синю знову:

```bash
python3 build.py --theme blue --out docs/blue --base /laundry-site/blue
```

Через 1–2 хвилини зміни зʼявляться за посиланням.
